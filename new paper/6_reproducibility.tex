\section*{Reproducibility Statement}
\label{sec:repro}

Every number in this paper comes from data in the artifact below. No result is
estimated, extrapolated, or reported from a source other than the raw
measurement files.

\paragraph{Artifacts.}
Everything except the agents' own work lives in one repository,
\url{https://github.com/harvest7777/paper-rewrite}:

\begin{itemize}
\item \texttt{prompts/} --- both prompts, verbatim as the agents received them.
\item \texttt{graphs/} --- the fixed-seed generator and the three evaluation
      graphs it produces.
\item \texttt{new paper/} --- this paper's source, and \texttt{figures/} within
      it, which regenerates every figure from the raw measurements.
\item \texttt{01-build-binaries.sh}, \texttt{02-run.sh},
      \texttt{03-test.sh} --- the build, benchmark and correctness harnesses,
      numbered in the order they are run.
\item \texttt{results/} --- every raw measurement behind this paper: the per-run
      \texttt{hyperfine} JSON, the per-run phase logs in \texttt{phases/}, the
      thread-scaling run in \texttt{thread-scaling/}, the correctness sweeps and
      their raw output in \texttt{correctness/}, and one session dump per run in
      \texttt{dumps/}.
\end{itemize}

Each agent run has its own repository, because each was a separate GraphViz
checkout. The link gives that run's complete diff against the starting commit,
together with the commit history the agent produced and the report it wrote.

\paragraph{Source.}
GraphViz at commit
\texttt{23b06521ab916e7f4f2ae2f9ef8413a8ccc66601}, from
\url{https://gitlab.com/graphviz/graphviz.git}. Both agent branches are named
\texttt{agent-work} and branch from that commit.

\paragraph{Build.}
\begin{verbatim}
cmake -S <sandbox> -B <build> \
  -DCMAKE_INSTALL_PREFIX=<prefix> \
  -DWITH_POPPLER=OFF -DWITH_GVEDIT=OFF \
  -DCMAKE_BUILD_TYPE=Release
cmake --build <build> -j12 && cmake --install <build>
\end{verbatim}
Identical for all nine sandboxes. On macOS a Bison $\geq 3.0$ path must be
passed explicitly, as the system Bison is too old for the GraphViz build.

\paragraph{Measurement.}
\texttt{hyperfine} 1.20.0, 10 warmup and 10 timed runs, all nine binaries for a
given graph in a single invocation, repeated over four command orderings with a
different binary leading each time. Graphs are produced by
\texttt{graphs/gen-graphs.py}. Raw per-run timings for every configuration are
in \texttt{results/} as \texttt{hyperfine} JSON exports, alongside the per-run
phase logs in \texttt{results/phases/}.

\paragraph{Figures.}
Every figure is regenerated from the raw JSON by a single script,
\texttt{new paper/figures/make\_figures.py}.

\paragraph{Environment.}
Apple M4 Pro, 12 cores (8 performance, 4 efficiency), 24\,GB unified memory,
macOS 26.5.2, Apple Clang 17.0.0.

\paragraph{Phase instrumentation.}
The patch that reports per-phase timings is a single commit on
\texttt{lib/dotgen/dotinit.c}, applied by cherry-pick to all nine sandboxes so
that the nine diffs are byte-identical. It is inactive unless
\texttt{GV\_PHASE\_TIMING} is set in the environment.

\paragraph{Agents.}
\texttt{claude-opus-5} (Claude Code) and \texttt{gpt-5.6-terra} (Codex), each
invoked four times autonomously --- two runs under each of the two prompts, both
in \texttt{prompts/}. No run had network access to the evaluation harness or
benchmark graphs, or to any other run's sandbox. Session dumps giving each run's
time and token usage are in \texttt{results/dumps/}, one file per run, named for
the sandbox it came from.
